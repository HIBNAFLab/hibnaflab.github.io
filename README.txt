PREVIEW
-------
Open index.html in a browser.

FREE PUBLISHING
---------------
GitHub Pages: create a public repo, upload these files, then Settings > Pages > deploy from main branch / root.
Cloudflare Pages or Netlify can also host the folder free.

GOOGLE SITES
------------
Google Sites cannot directly import a full HTML/CSS site. Use this package as the finalized design/content master and recreate the sections in your existing Google Site: https://sites.google.com/view/hibnaflab
